## The idea

Not every prompt needs the biggest model. OmniRoute sits in front of several LLM providers behind one API and picks a model for each request based on the task, cost and availability.

## What it handles

- One interface for multiple providers
- Routing rules for cost, latency and capability
- Fallbacks when a provider is having a bad day
- Usage visibility, because "why is the bill this high" deserves a real answer

## Status

Personal project, in active use.
